How to Start Learning HTML

By Kelvin Ojei · 17 October 2026 · 5-minute read

HTML means HyperText Markup Language. It describes the structure and meaning of content on a web page. HTML is not a programming language; it is a markup language.

When you learn HTML, focus on choosing the right element for the content. Use semantic elements when they accurately describe the purpose of a section.

In this article

  1. Document structure
  2. Common elements
  3. Practice activity

1. Document structure

A standard HTML document includes a doctype, an html element, a head for metadata, and a body for visible page content.

The page language should be declared using the lang attribute, for example lang="en" for English.

2. Common elements

  • Headings organise content into a logical hierarchy.
  • Paragraphs contain blocks of text.
  • Links connect pages or point to specific sections.
  • Lists present related items in an ordered or unordered form.

3. Practice activity

Create a page about a technology topic you enjoy. Include a main heading, two subheadings, paragraphs, a list, one meaningful image, and links to two other pages in your project.

Before submitting, check that each image has appropriate alternative text and that every link works.
